Objetivo General
Es tener todos los archivos del proyecto BibliotecaTec organizados
y con su versión, para que el equipo sepa qué cambió, quién lo cambió y cuándo.
Así evitamos que alguien sobrescriba el trabajo de otro y, si algo sale mal,
podemos regresar a una versión anterior.

4. Código

Uso del repositorio
Para mantener el repositorio ordenado, todos los integrantes del equipo deberán seguir las mismas reglas al guardar archivos, crear versiones y realizar cambios.

Reglas de nombres
Los nombres de los archivos deben ser claros y fáciles de identificar con un maximo de 3 palabras.

Ejemplos
pagina_principal.html
manual_usuario.pdf
Imagen_biblioteca.png
codificacion_bd.py


Reglas de versiones
Para identificar los cambios realizados en el proyecto se utilizará un número de versión.

v1.0 = Primera versión del proyecto
v1.1 = Se agregó una nueva función
v1.2 = Se corrigió un error
v1.3 = Se realizó un cambio importante

Reglas para comentarios en Git
Cada cambio realizado en Git debe tener un mensaje corto y claro que explique qué se modificó.
Los comentarios deben
* Explicar el cambio realizado.
* Ser fáciles de entender.
* Utilizar verbos como Agregar, Modificar, Corregir o Eliminar.
